安装后，如何开始使用？+

打开 Luma，内核会默认自动启动。在「订阅配置」中导入你自己的订阅地址或本地 YAML 文件，再选择代理节点。需要让支持系统代理的应用连接时，可以手动开启「系统代理」。

从旧版 Luma 升级时会复制导入本地订阅与常用设置，原数据保留。系统代理默认关闭，需要时由你手动开启。Luma 不提供节点或订阅服务。

提示内核已运行或无法启动，怎么办？+

先从托盘正常退出 Luma，再打开「应用程序」中的 Luma。若提示内核仍在运行，请确认是否还有旧版 Luma 窗口或进程；先保存工作，再退出对应应用。仍无法恢复时，可重启电脑后重试。

Luma 桌面版以内置用户进程运行内核，无需安装其他项目的系统服务。请在「偏好设置 → 数据与应用」中导出诊断信息，提交问题前隐藏订阅地址、密钥和其他私人内容。

首次安装提示未签名，怎么办？+

当前版本尚未进行 Apple 公证与开发者签名，Windows 也可能显示未知发布者提示。请确认文件来自本站，并核对下载卡片提供的 SHA-256 校验值，再按系统提示确认是否允许安装。

Mac 用户可在「系统设置 → 隐私与安全性」中查看系统拦截的具体说明。无需关闭系统安全保护。

还要单独下载内核吗？+

不需要。三个桌面安装包均包含对应平台的 Mihomo 内核及地理规则数据。安装完成后即可导入配置；你导入的订阅如果引用外部规则或节点列表，仍需联网更新这些内容。

我的订阅和设置存在哪里？+

保存在你设备的本地数据目录中，可以从应用设置打开。公开安装包不包含个人配置。Luma 源码以 GPL-3.0 协议开放，你可以在 GitHub 查看实现。
